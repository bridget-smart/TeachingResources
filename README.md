This repository contains extra resources for building intuition. Each script corresponds with one idea, example list:

- `convergence_in_probability.py` -- Illustrates how sample paths and deviation probabilities distinguish convergence in probability from almost sure convergence.
- `convergence_in_distribution.py` -- Shows how random variables can have the same limiting distribution while their relationship to the target changes.
- `p_value_visualisation.py` -- Uses a fair-coin example to show how an observed statistic is compared with its null distribution to calculate a p-value.
- `typical_set_visualisation.py` -- Compares typical sequences with the smallest high-probability set for a length-10 Bernoulli source.
